# Asset sources

Model files are not in this repository. Download these packs into `assets-src/`, then run `npm run assets`, which writes the optimised copies to `assets/generated/`.

Ashwing Drake by Literock Studios. Its licence forbids sharing the model files, so never commit them or `assets/generated/`.

Island terrain, rope bridges, the waterfall, clouds, the sky and the nón lá are generated by code in `src/client/`.
